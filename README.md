# 🎓 Student Study Track System

A smart student monitoring and recommendation system that analyzes study behavior and provides insights using data visualization and machine learning.

---

## 🚀 Features

* 📊 Interactive dashboards using Streamlit
* 👨‍🎓 Student behavior tracking
* 🔍 Data analysis with clustering (K-Means)
* 📈 Study performance insights
* 🤖 Recommendation system for students
* 🔐 Login & registration system
* 🗄️ SQLite database integration

---

## 🛠️ Tech Stack

* Python 3.12
* Streamlit
* Pandas, NumPy
* Scikit-learn
* SQLite
* Matplotlib / Plotly

## ⚙️ Installation

### 1️⃣ Clone the repository

```
git clone https://github.com/studentstudytrack-team/student-study-track-system.git
cd student-study-track-system
```

### 2️⃣ Navigate to project folder

```
cd student-behavior-dashboard
```

### 3️⃣ Create virtual environment (optional)

```
python -m venv venv
venv\Scripts\activate
```

### 4️⃣ Install dependencies

```
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```
python -m streamlit run app.py
```

OR from root folder:

```
python -m streamlit run student-behavior-dashboard/app.py
```

## 📊 Modules Overview

* **K-Means Analysis** – Clustering students based on behavior
* **Recommendations** – Suggest improvements for students
* **Database** – Stores user and study data
